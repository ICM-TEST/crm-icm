# CONTEXT: <Client Name>

This folder holds everything for <Client Name>.

| Item | What it is |
|---|---|
| `<Client Name> – Profile.md` | The client's current details |
| `<Client Name> – Log – <user name>.md` | One per staff member: each profile change they made, oldest first, never edited |
| `<Client Name> – Log.md` | Only for clients loaded from the old CRM: the import line. Part of the log, never edited |
| `Income Tax/` | One folder per tax year |
| `Provisional Tax/` | One folder per provisional period. Present only if provisional tax is or was Yes |
| `Admin Penalty/`, `FICA/`, `Tax Clearance/` | One folder per tax year |

Year and period folders appear when work is first recorded for that year or period.
